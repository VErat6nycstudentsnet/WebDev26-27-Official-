Web Technologies

HTML

HTML stands for Hyper Text Markup Language and is the standard language used to make web pages. HTML describes the structure of a web page, meaning that HTML is the foundation of a webpage. One example of how HTML language is written (or typed) is with something called “tags”. They consist of using “<” and “>” and words go in between those tags, they can be uppercase or lower case. It is recommended to type in lowercase because it is convenient (also it is common and standard practice to).

CSS

CSS stands for Cascading Style Sheets and it describes how HTML is meant to be displayed on a website, screen, paper, etc. CSS helps define the style of your webpage, like layouts, screen layouts, etc. Meaning that CSS helps with accessibility across different devices while also helping with making the webpage look nicer.

JavaScript

What is Javascript? Javascript can update changes in both HTML and CSS while also being capable of manipulating and validating data. With Javascript, you can make your we site have these things, meaning that it will make your website more interactive, fun, and most importantly, functionable for the user in the website
